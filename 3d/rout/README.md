# rout / Apple Watch

`apple-watch.glb` — копия предоставленного пользователем `apple-watch-ultra-2-beige-custom-screen.glb` без изменения геометрии, материалов и встроенных текстур экрана.

Попап rout использует тот же контроллер 3D, освещение, вписывание в кадр, управление мышью/касанием/стрелками и возврат в исходный ракурс, что iPhone. Пауза после ввода 500 мс; плавный возврат 800 мс. Новое взаимодействие прерывает возврат. При reduced-motion без анимации. Модель грузится при первом открытии; закрытая сцена не рендерится. При ошибке доступны превью и повтор загрузки.
