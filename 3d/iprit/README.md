# Iprit iPhone preview

`iphone-black.glb` — пользовательская модель из предоставленного файла `iphone-18-pro-black.glb` (Black, исходная геометрия Apple). Копия без изменений.

Скрин: `img/personal-projects/iprit-screen.png`, предоставленный пользователем `GITXhrhGQNOHKLlmobile.png`, 512×1024. Наложен целиком на UV0 дисплея без дополнительной обрезки.

В `js/iprit-popup.js` материал поверхности дисплея `MmWvsinobDBeETZ` заменяется на MeshBasicMaterial с этим скрином. Родная геометрия дисплея сохраняет скругления и вырез камеры. UV0 идёт сверху вниз, поэтому texture.flipY = false. Остальные материалы корпуса остаются исходными; окружение и свет создаются в отдельной сцене попапа.

Модель и текстура загружаются при первом открытии. Закрытое окно не рендерится. При ошибке WebGL/загрузки доступны скрин и повтор загрузки; описание и ссылка Telegram работают независимо от 3D.

Совместимость с Three.js r128: карты baseColor с texCoord=1 выбирают UV1 через локальную правку shader map_fragment. Карты normal/roughness сохраняют UV0 и исходное тайлирование. Это убирает повторяющиеся полосы на задней крышке без замены её материалов.
