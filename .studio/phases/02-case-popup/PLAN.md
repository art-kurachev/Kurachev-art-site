# Фаза 2 — Поп-ап кейса (UX)
Цель: описать, как кейс открывается в большом поп-апе поверх главной (по образцу Behance), до начала вёрстки.
Готово, когда:
- есть флоу открытия и закрытия поп-апа со всеми способами выхода и edge cases (десктоп и мобильные);
- решены открытые вопросы из STATE.md: точка входа на главной, свой URL у кейса, формат слайдов;
- есть структура кейса СУМ: список слайдов из Figma, их размеры, формат выгрузки;
- текущее поведение главной (StrokeMask, 3D, скролл) учтено и не ломается.
