## Формат для сайта: рекомендация

**MVP: все слайды выгружаем картинками WebP. Текст слайдов кладём в HTML скрыто, для alt и SEO.**

Почему:
- Слайды сверстаны как цельные композиции: диаграммы, мокапы, мелкие подписи UI. Если вёрстать их текстом, придётся переделать 22 макета в HTML/CSS, а это уже отдельная фаза.
- Так делает Behance, на который ориентируется поп-ап (PROJECT.md).
- Код сайта написан вручную и без сборки: картинки проще всего встроить, они не тянут новых зависимостей.

Параметры выгрузки:
- Формат WebP, качество ~80. Для слайдов с фото-рендерами (00, Title) ~75. Fallback в JPG не нужен: WebP поддерживают все актуальные браузеры.
- Экспорт из Figma в PNG @2x (3840 px), потом конвертация в WebP по ширинам: **960, 1440, 1920, 2880** (опционально 3840 для 4K/Retina-мониторов при поп-апе на всю ширину).
- `srcset` по ширине (`w`) + `sizes="(min-width: 1440px) 1400px, 100vw"`. Точное значение `sizes` зависит от ширины поп-апа из case-popup-flow.md.
- `width`/`height` в атрибутах из таблицы выше (или `aspect-ratio`): так при ленивой загрузке не прыгает скролл.
- `loading="lazy"` и `decoding="async"` у всех, кроме первых двух слайдов. У первого слайда `fetchpriority="high"`.
- Именование: `img/cases/sum/01-cover-960.webp`, `02-about-1440.webp` и т. д. Номер ставим по порядку показа, а не по имени фрейма.
- Ожидаемый вес (допущение, без замера): 80–300 КБ на слайд на 1440 px, 3–5 МБ на весь кейс. Грузится постепенно по мере скролла.

Риск: читаемость на телефоне. Ширина 1920 ужимается до 375 (×0,2), и основной текст 16–24 px превращается в 3–5 px. На слайдах 01, 03, 05, 07, 09, 11 его будет не прочитать без зума. Варианты на будущее, не для MVP:
1. Дать на мобильных зум по тапу на слайд (просмотр одной картинки на весь экран с pinch-zoom).
2. Сделать в Figma мобильные версии текстовых слайдов (ширина ~750) и подставлять их через `<picture media>`.
3. Сверстать текстом только текстовые блоки слайдов с меткой «много» (01, 03, 05, 07), а картинками оставить мокапы. Для этого понадобится подключить Gilroy: в `fonts/` его нет (там ITC Avant Garde и Songer).
