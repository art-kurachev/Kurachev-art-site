# kurachev.art

## Суть
Личный сайт-портфолио Артёма Курачева, Product UX/UI дизайнера (B2B-сервисы, ERP, мобильные приложения, с 2018 года).
Сайт нужен для двух вещей:
- показывать кейсы;
- пробовать на нём новые инструменты и подходы (например, студию агентов Claude).

## Пользователи
- Работодатели, нанимающие менеджеры, заказчики: смотрят, кто такой Артём, и изучают кейсы.
- Сам Артём: использует сайт как полигон для экспериментов.

## Цели и рамки
- Ближайшая цель: страница кейса, которая открывается в большом поп-апе поверх главной, как на Behance. Внутри идут слайды кейса из Figma.
- Первый кейс: СУМ (самый правый в Figma-файле «Кейсы»).
- Рамки: код сайта Артём написал руками. Любое изменение сохраняет текущее поведение или улучшает его. Если сомневаешься, не трогай.
- Текстовые строки на главной: два одинаковых `h2`, верхний с классом `mask-text-mp`. `StrokeMask` в js/main.js раскрывает верхний при скролле. Обе копии должны совпадать.

## Стек
- Статичный сайт без сборки: index.html, css/ (global, style, media), js/main.js, fonts/, img/, video/, 3d/.
- three.js 0.128 с CDN (GLTFLoader, OrbitControls) для 3D.
- desys.html: отдельная страница документации дизайн-системы.

## Деплой
- Пуш в `main` запускает GitHub Actions `deploy.yml`, который запускает обновление на сервере (kurachev-site-update). Кроме того, сервер сам забирает `main` раз в минуту.
- Домен kurachev.art, nginx на собственном сервере Артёма.
