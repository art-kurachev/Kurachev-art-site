## Правка по studio-ui-designer

- Desktop уточнён до 1440 × 840; тот же фрейм 1312:6591.
- Иерархия: крупное IPRIT, назначение «Кальянный AI-ассистент», описание пользы, заметная светлая CTA.
- Увеличены подписи экранов (14 px) и пояснения функций (15–16 px).
- Существующие цветовые переменные сохранены; в ту же коллекцию добавлены space/24, /32, /48, /80 и radius/action.
- Кнопка заменена инстансом компонента 1312:6815; рядом с макетом варианты Default / Hover / Focus / Pressed. Состояния empty/error/loading/disabled для внешней ссылки не применяются.
- Исходные экраны приложения не перерабатывались; контраст самого мини-аппа не входит в эту правку презентационного блока.
- Макет проверен экспортом из Figma Console. Адаптив и интерактивное поведение в браузере пока не проверяются: это отдельный Desktop-макет, не вёрстка.
