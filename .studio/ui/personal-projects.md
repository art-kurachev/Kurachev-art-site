# Personal Projects

2026-11-06. Ветка: codex/personal-projects.

Статус: временно скрыт по просьбе пользователя атрибутом hidden. Для возврата убрать hidden у #personal-projects.

- Источник: https://www.figma.com/design/sstCrrH3CyVTfCkP9L7g1y/Iprit?node-id=1384-9176
- Прочитано через Figma Console Desktop Bridge. REST development endpoint недоступен из-за токена; геометрия, fills, типографика и исходные изображения получены через Plugin API.
- Блок #personal-projects находится между #history и #projects.
- Три полноширинные карточки без зазоров. На ширине 1920 px каждая 640 × 387 px, как в новом макете; до 768 px — одна колонка на ширину окна.
- Фоновые изображения из fills узлов 1384:9149, 1384:9158, 1384:9168 экспортированы в img/personal-projects/*-cover.png и уменьшены до 1280 × 774 без изменения пропорций.
- SVG-логотипы из узлов 1384:9157, 1384:9268, 1384:9173 сохранены отдельно, их исходные width/height/viewBox не изменены.
- Названия в макете: Iprit, observer, rout (проект ранее назывался myBusStop). Метки tg mini-app / macOS / Apple Watch — HTML, Geologica 200.
- Заголовок Personal Projects использует существующую анимацию .containerTitle; положение и типографика уточнены по Figma.
- Iprit ведёт на https://t.me/iprit_hma_bot в новой вкладке. Для других проектов ссылки пока не заданы.
- Описания сохранены для доступности, визуально под карточками отсутствуют согласно новому макету.
- Сохранены верхний межсекционный отступ и нулевой нижний отступ. Основная навигация, кейсы и прочие разделы не менялись.
- Проверены 1920 и 375 px: изображения загружены, корректные пропорции, переполнения нет.
