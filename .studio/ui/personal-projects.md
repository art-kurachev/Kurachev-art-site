# Personal Projects

2026-11-06. Основной блок обновлён по новому макету:
https://www.figma.com/design/sstCrrH3CyVTfCkP9L7g1y/Iprit?node-id=1401-11251

- Это основной блок сайта, не попап. По уточнению пользователя боковые поля как на остальном сайте: 13vw на десктопе, 10rem на мобильном (как строки History). При 1920 px ширина сетки 1420.8 px, высота карточек 328 px. Расстояния до History и Cases одинаковые: сверху у секции учтён собственный отступ плюс верхний padding Cases (18.75rem на десктопе, 45rem на мобильном). На 1920 px оба межсекционных расстояния составляют 438 px.
- Горизонтальные линии идут на всю ширину окна; у центральной сетки есть боковые линии и разделители карточек. Цвет линий rgba(183,171,152,.3).
- Фон карточек #0D0D0D совпадает с фоном сайта и краями исходных изображений. Принудительный фильтр brightness/contrast удалён по просьбе пользователя: сохраняется плавное затухание превью как в макете. Боковые поля полосы прозрачные.
- Логотипы сверху: Iprit 135×62, Observer 327×48, rout 150×48 на ширине 1920 px. При сужении плавно уменьшаются. Подписи Geologica 200, 12–14 px, uppercase, letter-spacing .22em, opacity .6.
- Изображения закреплены снизу, width:100%, height:auto. Высота карточек независима: --personal-project-height, по умолчанию max(240px,17.083333vw). До 768 px одна колонка, поля 10rem, высота max(260px,60.87vw).
- Заголовок использует общий стиль и анимацию заголовков сайта; выровнен по левому краю новой сетки.
- Hover/focus: зелёная шторка раскрывается из середины, как строки History; логотип и подпись становятся тёмными #0D0D0D, картинка заменяется описанием. При reduced-motion без анимации.
- Текст раскрытия по просьбе пользователя облегчён до Montserrat 500, размер clamp(12px,1.25rem,20px), line-height 1.4. Полные описания также доступны скринридеру.
- Источники картинок те же: fills 1390:11171, 1390:11189, 1390:11206; локальные PNG 1280×774. SVG 1384:9157, 1390:11197, 1384:9173 совпадают с новым макетом.
- Клик по Iprit открывает отдельный dialog с описанием и 3D iPhone. Ссылка на бот находится внутри попапа. Остальные карточки без ссылок.
- В браузере не проверялось по просьбе пользователя; геометрия и стили сверены с данными Figma.

- При наведении на карточки кастомный курсор скрывается тем же обработчиком, что в строках History.

- Межбраузерный цвет: у трёх PNG-превью убраны gAMA/cHRM, добавлена явная метка sRGB (intent 0). IDAT и пиксели не менялись. Это устраняет неоднозначность интерпретации гаммы у Chromium и WebKit; CSS-фон и край изображений имеют одинаковые RGB 13/13/13. URL превью обновлены для сброса кэша.

## Последнее уточнение

- Карточки снова во всю ширину окна, без боковых полей и внешней рамки. Только внутренние вертикальные разделители; на мобильном — горизонтальные между карточками. Отступ заголовка и большие интервалы до History/Cases сохранены.
- Высота увеличена: max(280px,20vw) на десктопе (384px при 1920px), max(300px,70vw) на мобильном.
- Подпись Iprit изменена на PWA в обычном и раскрытом состоянии, попапе и футере.

- У полосы карточек возвращены верхняя и нижняя горизонтальные линии. В раскрытии описание идёт сразу после логотипа с адаптивным зазором 24–40 px, вместо привязки к нижнему краю.

- Обновление Figma 1401:11251: описание центрируется в оставшейся области под логотипом, боковые поля 45 px при ширине карточки 640 px. Google Sans Regular 400, адаптивные 14–20 px, line-height 1.6. Высота на десктопе 447 px при 1920 px.
- Iprit: новое превью телефона под углом, исходник fill узла 1431:11575 (hash 74687c53724d6786f25a3da3823b0533576ef3de), 1280×774 с явной меткой sRGB. Подпись PWA сохранена по последнему указанию пользователя.

- Observer и rout теперь также открывают нативные dialog в общем оформлении Iprit. Пока в сцене показываются имеющиеся превью; контейнеры готовы к замене на 3D-модели. Клавиатура Enter/Space, Escape, закрытие фоном/крестиком и возврат фокуса реализованы в js/project-popups.js.

- rout: подключена Apple Watch Ultra 2 из пользовательского GLB со встроенным экраном. Поведение общее с iPhone (вращение, автоповорот в исходный ракурс после паузы, вписывание в контейнер, ленивое открытие). Observer пока использует превью.

- Observer: MacBook Pro из пользовательского GLB и пользовательский скрин приложения. Крышка открывается при открытии попапа, закрывается перед закрытием окна. Общий контроллер ожидает projectpopup:beforeclose через waitUntil; Escape, крестик и затемнение используют этот же путь.
